# 801 文件桶

一个跑在内网里的文件收集与共享服务。打开浏览器就能用：建一个「项目桶」，把 6 位识别码发给大家，谁都能往里面传文件、下载文件；也可以选中文件生成分享链接，或者把整个桶打包下载。

无需注册账号，无需安装客户端，单机部署，数据全部保存在本地。

> 适合办公室、教室、活动现场、家庭局域网等场景。默认没有公网账号体系，**不建议直接暴露到公网**，详见[安全说明](#安全说明)。

## 功能

- **匿名设备身份**：首次访问自动分配设备 ID 和随机昵称，不需要注册登录；昵称可随时修改。
- **项目桶**：创建储存桶时自动生成 6 位数字识别码，其他人输入识别码即可加入。
- **文件上传**：支持点击选择、拖拽上传、批量上传，实时显示上传进度。
- **在线文本**：直接新建文本文件，也可以在线编辑、保存。文本文件支持再次编辑，每次替换内容自动递增版本号。
- **文件管理**：重命名、删除、按名称筛选、按类型/时间分组，显示上传者昵称和上传时间。
- **在线预览**：图片、视频、文本类文件可在浏览器内直接预览。
- **打包下载**：勾选多个文件后一键打包为 ZIP 下载。
- **分享链接**：为选中的文件生成独立分享页，无需加入项目桶即可访问；分享可随时删除或由管理员一键全部失效。
- **数据看板**：桶数、文件数、设备数、占用空间、近 30 天上传趋势、文件类型分布、热门桶排行、磁盘与内存状态。
- **管理后台**：查看全部桶和文件、修改全局设置、重置分享链接、修改管理员密码。
- **配额与限制**：可限制单文件大小、项目总占用、单桶文件数量，并支持按扩展名白名单/黑名单过滤。
- **守护进程**：服务异常退出后自动拉起，提供开机自启和在线更新（OTA）。
- **深浅色主题**：支持手动切换，也可以按中国时间自动切换（18:00–06:00 使用深色）。
- **移动端适配**：手机浏览器可直接上传、下载和预览。

## 技术栈

- 后端：Python 3.10+、FastAPI、Uvicorn、SQLAlchemy 2
- 数据库：SQLite（WAL 模式），无需单独安装数据库
- 前端：原生 JavaScript + Bootstrap 5，静态资源已内置，无需 Node.js 构建
- 认证：管理员使用密码登录，签发 JWT 并写入 HttpOnly Cookie；普通用户通过设备 ID 识别

## 快速开始

### Windows

1. 安装 [Python 3.10+](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**。
2. 双击 `安装依赖.bat`，脚本会创建 `.venv` 虚拟环境并安装依赖。
3. 双击 `启动项目.bat`，浏览器会自动打开 <http://127.0.0.1:51001>。
4. 想让局域网内其他设备访问，右键以管理员身份运行 `开放局域网访问.bat`，放行 51001 端口。

需要长期运行时，双击 `守护启动.bat` 启动守护进程；再以管理员身份运行 `设置守护自启.bat` 可设置开机自启。

### Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

默认监听 `0.0.0.0:51001`，浏览器访问 `http://服务器IP:51001`。生产环境建议用 systemd 托管，完整的 Linux 部署、防火墙、备份与升级步骤见 **[DEPLOY.md](DEPLOY.md)**。

## 首次使用

1. 打开首页，输入名称创建一个项目桶。
2. 把桶的 6 位识别码发给同事；对方在首页点「加入」，输入识别码即可进入。
3. 进入桶后上传文件，或点「新建文本」直接写一段文字。
4. 勾选文件后可以创建分享链接、打包下载或批量删除。

### 管理后台

- 入口：<http://127.0.0.1:51001/login.html>
- 默认密码：`admin123`

**首次登录后请立即在「设置」中修改密码。** 使用默认密码时，设置页会持续提示。

管理后台可以：

- 查看全部项目桶、文件和上传者
- 调整单文件上限、磁盘占用比例、单桶文件数量上限
- 暂停上传（维护模式）
- 设置扩展名白名单或黑名单
- 控制数据看板对普通用户是否可见
- 让全部分享链接立即失效
- 上传更新包进行在线更新

## 配置项

大部分限制在「设置」页面修改，保存后立即生效：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 单文件上限 | 100 MB | 1–102400 MB，管理员上传不受此限制 |
| 磁盘占用比例 | 20% | 首次启动按当时磁盘剩余空间折算成固定额度，可在设置中调整 |
| 单桶文件数量上限 | 0（不限） | 0–100000 |
| 允许上传 | 开启 | 关闭后进入维护模式，普通用户无法上传 |
| 扩展名规则 | 关闭 | 可设为白名单（只允许列出的类型）或黑名单（禁止列出的类型） |
| 看板可见 | 开启 | 关闭后只有管理员能访问数据看板 |
| 看板刷新间隔 | 10 秒 | 5–300 秒 |

服务端口固定为 `51001`，入口脚本、单实例锁和防火墙脚本都依赖这个端口。如需修改，请同时调整 `main.py` 中的 `SERVER_PORT`、`watchdog.py` 中的 `PORT` 以及相关 `.bat` 脚本。

## 数据目录

所有运行时数据都在程序目录下的 `data/`，升级程序不会覆盖它：

```
data/
├── app.db           SQLite 数据库（设备、桶、文件记录、设置、分享）
├── app.db-wal       WAL 日志
├── app.db-shm       WAL 共享内存
├── uploads/         上传的文件本体
└── tmp/             打包下载和上传过程中产生的临时文件
```

首次启动时目录会自动创建，数据库表结构也会自动初始化。备份和恢复方法见 [DEPLOY.md](DEPLOY.md#六数据备份与恢复)。

## 安全说明

这是一个面向内网协作的工具，安全模型比较朴素，部署前请了解：

- **没有用户账号体系**。任何能访问服务地址、拿到 6 位识别码的人都可以进入对应的桶并上传、下载文件。请把识别码当作共享口令使用。
- **默认管理员密码是 `admin123`**，必须修改。连续登录失败 5 次会锁定该 IP 60 秒。
- **默认使用 HTTP**。如需跨不可信网络访问，请通过 Nginx 等反向代理配置 HTTPS。
- **不要直接暴露到公网**。如果必须公网访问，至少应加一层反向代理、HTTPS 和访问控制。
- 在线更新包使用源码中的固定密钥校验完整性，仅管理员可以上传更新包。自行部署时建议在首次使用前修改 `main.py` 与 `打包更新.py` 中的 `OTA_SECRET`（两处必须一致）。
- 上传文件按原始字节保存，不做病毒扫描；不要允许不可信来源上传可执行文件。可用扩展名白名单限制上传类型。

## 已知限制

- 系统内存和进程内存统计基于 Windows API，Linux 下数据看板的内存卡片为空，其余功能不受影响。
- 在线更新依赖守护进程心跳；未运行 `watchdog.py` 时，更新入口会拒绝执行，避免更新后无人拉起服务。
- 打包下载的 ZIP 在 `data/tmp/` 生成，下载完成后或超过 1 小时自动清理。
- 时间统一使用中国时间（UTC+8），不跟随服务器或设备时区。
